# Step2 企業を調べる（15分）

企業を1社選び、営業向けの調査レポートをPDFで作成します。

## 入力する一文

企業名を置き換えて、そのまま送信してください。

```text
README.mdの基本プロンプトで、○○株式会社を調査して。
```

## 基本プロンプト

```text
指定された企業を調査し、営業担当者が5分で読める日本語レポートを作成してください。

【調査内容】
1. 現在の主要事業
2. 今後の成長領域
3. 経営・IT上の課題
4. AI PC（AIPC）の提案候補

【要件】
- 最新の公開情報をウェブで確認し、調査基準日を記載する。公式発表・決算資料・公的資料などの一次情報を優先する。
- 事実と推測・評価を分け、主要な主張に出典リンク、重要な数値に対象期間と出典を付ける。
- AIPC候補には、優先度・業務・利用者・処理例・AIPCを使う理由・KPI・セキュリティ条件・前提とリスクを示す。
- 冒頭に短い要約、本文に上記4項目を記載し、最後に要点を1つの表にまとめる。

【保存】
作業ディレクトリに「{企業名}_business_research_{YYYYMMDD}.pdf」で保存する（日付は実行日）。
全ページをレンダリングして文字化け・文字切れ・表のはみ出し・不要な空白ページを確認し、出典リンクの保持も検証・修正する。
完了後、短い要約とPDFへのリンクを示す。
```
